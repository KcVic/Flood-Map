Abuja Flood Map

Predictive Analysis

Methodology Abstract

This map identifies high-risk flood zones within Abuja. Data is derived using the Height Above Nearest Drainage (HAND) technique to normalise topography based on the vertical distance of any point to its nearest drainage channel.

Variables include Digital Elevation Model of Abuja, Stream and River Drainage Network, and Flow Direction. Regions covered in a blue hue represent zones with which lie below 2m of river or stream channels and as such are most vulnerable to flooding.

The map includes real-time river discharge data, which is updated every 15 minutes from open-meteo.com using the GloFAS 4.0 seamless model. Pulsing animations highlight areas of concern based on the current discharge levels.

Disclaimer: This map is for informational purposes only and is by no means authoritative data on flood risk. Always prioritize instructions from local authorities and emergency services.
